# ЛР №2. Pandas и корреляционный анализ

## Содержимое:

- pandas_tasks.py — часть 1, Titanic и Pandas
- correlation_tasks.py — часть 2, корреляционный анализ
- plot_correlations.py — графики и heatmap корреляций для отчёта
- test_pandas_tasks.py, test_correlation_tasks.py — тесты на каждую функцию
- titanic.csv, brainsize.txt — исходные данные
- grader_contracts/ — датаклассы

## Быстрый старт

Установка зависимостей
```bash
pip install -r requirements.txt
```

## Проверка:

1. Запуск тестов
```bash
pytest -v
```
2. Проверка графики для части 2 (scatter и heatmap)
```bash
python plot_correlations.py
```
